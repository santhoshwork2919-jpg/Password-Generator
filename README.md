# 🔐 Password Generator

A responsive and secure Password Generator application built using **React.js**, designed to help users create strong, customizable passwords instantly. The app gives users full control over password length and character types, ensuring better security for online accounts.

## ✨ Features

- Generate strong, random passwords instantly
- Customize password length
- Toggle character types:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*)
- Copy generated password to clipboard
- Responsive design — works across devices

*(Update this list if any features differ from the actual implementation.)*

## 🛠️ Tech Stack

- **React.js** – component-based UI
- **JavaScript (ES6+)** – app logic
- **CSS** – styling and responsiveness

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/santhoshwork2919-jpg/Password-Generator.git
   ```
2. Extract the project
   ```bash
   unzip passwordgenREAct.zip
   ```
3. Navigate into the project folder and install dependencies
   ```bash
   cd passwordgenREAct
   npm install
   ```
4. Run the app locally
   ```bash
   npm start
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
